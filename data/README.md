# Data and Kaggle Dataset Policy

OpportunityKit does not require a Kaggle dataset for its main workflow. Real use starts with the announcement pasted or uploaded by a user, and student information comes from the authenticated user's saved profile.

A Kaggle dataset may be useful for:
- testing requirement extraction against varied announcement wording;
- offline evaluation and regression tests;
- providing clearly labeled sample records for a demo;
- validating CSV import and normalization.

Before using any dataset:
1. Confirm its license permits the intended use and redistribution.
2. Record the Kaggle dataset title, owner, URL, license, download date, and version here.
3. Inspect freshness, field quality, duplicate rows, and personal/sensitive data.
4. Remove personal data and normalize fields.
5. Never present Kaggle rows as currently open or official opportunities unless independently verified from an official source.
6. Keep sample rows clearly marked as sample/demo data.

Do not bundle a dataset until a specific dataset has been reviewed. The app must still work when `data/samples/` is empty.
